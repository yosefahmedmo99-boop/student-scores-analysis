# Student Performance Prediction 🤖📊

## 📌 Objective
The goal of this project is to predict student grade classification using machine learning techniques based on academic, demographic, and behavioral features.

---

## 📂 Dataset
- Student performance dataset (synthetic)
- Includes:
  - Study habits
  - Absences
  - Parental support
  - GPA
  - Extracurricular activities

---

## 🛠️ Tools & Technologies
- Python
- Pandas
- Matplotlib / Seaborn
- Scikit-learn

---

## ⚙️ Project Workflow
- Data Cleaning (handling missing values & duplicates)
- Exploratory Data Analysis (EDA)
- Data Visualization
- Feature Selection
- Model Training

---

## 🤖 Models Used
- Random Forest Classifier
- Logistic Regression
- Decision Tree

---

## 📊 Model Evaluation
- Accuracy Score
- Confusion Matrix
- Cross Validation

---

## 🔧 Model Optimization
- Hyperparameter Tuning (GridSearchCV)
- Model comparison to select best performer

---

## 📈 Results
- Random Forest achieved the best performance
- Cross-validation improved model reliability and reduced overfitting

---

## 🔍 Key Insights
- Study time has a strong positive impact on performance
- High absences negatively affect student grades
- Parental support contributes to better outcomes

---
